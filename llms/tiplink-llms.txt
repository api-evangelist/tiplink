# TipLink

> TipLink is a Solana wallet-link platform: create a link (or QR code) that holds crypto or an NFT and share it with anyone, so a recipient can claim digital assets without already having a wallet. It is delivered as a set of first-party TypeScript/JavaScript SDKs and Solana Wallet Adapter UI components rather than a hosted REST API. Backed by Multicoin Capital.
